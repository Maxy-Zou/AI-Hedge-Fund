## Critical Gaps

### 1. SignalEngine Never Wired in CLI (CRITICAL)

`cli.py` line 81 passes `signal_engine=None` to `make_poll_tick()`. The SignalEngine is never imported, never constructed, and never passed. This disconnects the entire signal detection and trade execution pipeline.

**Affected requirements:** SIG-01, SIG-02, SIG-03, SIG-05, EXEC-01-06, DASH-02-04
**Fix:** Import SignalEngine, call load_signal_settings(), construct instance, pass to make_poll_tick

### 2. Markets Table Never Populated (HIGH)

No code path writes to the `markets` table. The `Market` ORM model exists but is only read (in `_get_close_times`). This breaks DASH-01 (empty markets panel) and SIG-05 (resolution suppression always gets `close_time=None`).

**Fix:** Add Market upsert logic in poll_tick after snapshot persistence

### 3. Cooldown Has No Time Window (MEDIUM)

`_is_on_cooldown()` checks if ANY signal ever existed for a (ticker, type) pair — no time window applied. The `signal_cooldown_seconds=300` config field is declared but never read.

**Fix:** Add `Signal.detected_at > (now - timedelta(seconds=settings.signal_cooldown_seconds))` filter

### 4. Dashboard Logging Not Configured (LOW)

`dashboard/app.py` never calls `configure_logging()`. structlog events produce unformatted output.

**Fix:** Add `configure_logging()` call at app startup
