1. Create `src/ai_washer/ingestion/job_collector.py`:
   - Follow GitHubCollector pattern exactly
   - `_INTER_COMPANY_DELAY = 1.0`
   - `_PROGRESS_LOG_INTERVAL = 10`
   - `class JobCollector`:
     - `__init__(self, app_settings: AppSettings, job_client: JobClient | None = None, session_factory=None)`: Create engine from settings, get session factory. Create JobClient if not injected.
     - `collect_for_company(self, company_id: uuid.UUID, company_name: str, cik: str) -> JobCollectionResult`:
       1. Call `self._client.search_company_jobs(company_name)` to get list[JobRecord]
       2. For each JobRecord, check if dedup_hash exists in DB:
          - If not exists: INSERT new JobPosting with first_seen=today, last_seen=today, is_active=True
          - If exists: UPDATE last_seen=today (keep is_active=True)
       3. After processing all results: UPDATE all company's job_postings where last_seen < today AND is_active=True -> set is_active=False (marking stale postings from previous scrapes that weren't seen today)
       4. Return JobCollectionResult with counts
       5. Wrap in try/except, log errors, return result with error messages
     - `collect_all(self) -> list[JobCollectionResult]`:
       - Query all active companies
       - For each: call collect_for_company, sleep _INTER_COMPANY_DELAY
       - Log progress every _PROGRESS_LOG_INTERVAL companies
   - `logger = structlog.get_logger(__name__)` with `.bind(collector="job_collector")`

   - `@job_app.command(name="collect-all")`: Collect for all active companies. Lazy import.
   - Follow the exact pattern of `github_app.command("collect")` and `github_app.command("collect-all")`
