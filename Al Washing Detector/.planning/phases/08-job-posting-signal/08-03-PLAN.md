   - Module docstring explaining: pure function, no DB access, follows github_activity_scorer pattern
   - `_SIGNAL_VERSION = "0.8.0"`
   - Function signature:
     ```python
     def compute_job_mismatch_score(
         ai_role_count: int,
         marketing_role_count: int,
         total_role_count: int,
         ghost_ratio: float,
         ai_claim_intensity: float,
         scoring_year: int,
         ghost_penalty_weight: float = 0.20,
         engineering_weight: float = 0.40,
         hiring_intensity_weight: float = 0.40,
         sigmoid_midpoint: float = 1.0,
         sigmoid_steepness: float = 2.0,
     ) -> SignalResult | None:
     ```
   - Logic:
     1. If ai_claim_intensity <= 0: return None
     2. If total_role_count == 0: return high score (use claim_factor only, job_factor=0)
     3. Sub-factors (each 0.0 to 1.0):
        - `hiring_intensity = min(ai_role_count / 20.0, 1.0)` -- cap at 20 AI roles for full credit
        - `specificity = ai_role_count / max(total_role_count, 1)` -- ratio of genuine AI roles
        - `marketing_ratio = marketing_role_count / max(total_role_count, 1)` -- marketing fluff fraction
        - `ghost_penalty = ghost_ratio * ghost_penalty_weight` -- reduces job_factor
     4. `job_factor = (hiring_intensity * hiring_intensity_weight + specificity * engineering_weight) * (1.0 - ghost_penalty)` -- weighted, penalized by ghosts
     5. `claim_factor = min(ai_claim_intensity / 50.0, 2.0)` -- normalize claims, cap at 2.0 (same pattern as github scorer)
     6. If job_factor < 0.01: job_factor = 0.01 (prevent division by zero, same as patent scorer)
     7. `gap_ratio = claim_factor / job_factor` -- high ratio = more claims than hiring
     8. `score = sigmoid_normalize(gap_ratio, midpoint=sigmoid_midpoint, steepness=sigmoid_steepness)`
     9. Build evidence dict with: signal_version, ai_role_count, marketing_role_count, total_role_count, ghost_ratio, ai_claim_intensity, sub_factors (hiring_intensity, specificity, marketing_ratio, ghost_penalty), job_factor, claim_factor, gap_ratio, scoring_year
     10. Return `SignalResult(signal_type="job_mismatch", score=score, evidence=evidence)`
