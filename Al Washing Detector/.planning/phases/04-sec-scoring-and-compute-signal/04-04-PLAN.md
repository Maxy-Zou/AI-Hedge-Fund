    **src/ai_washer/analysis/scoring_orchestrator.py** -- Thin DB orchestration layer. This is the ONLY file in analysis/ that touches the database. All scoring logic lives in the pure functions from Plans 02/03.

    ```python
    import uuid
    from datetime import date
    from collections.abc import Sequence

    import structlog
    from sqlalchemy import select
    from sqlalchemy.orm import Session

    from ai_washer.analysis.types import FilingForScoring
    from ai_washer.analysis.sec_filing_scorer import (
        compute_keyword_counts_by_year,
        compute_sec_filing_score,
    )
    from ai_washer.analysis.compute_spending_scorer import (
        compute_compute_spending_score,
    )
    from ai_washer.analysis.types import SignalResult
    from ai_washer.config import ScoringConfig
    from ai_washer.db.models import Company, Filing, SignalDetail, XBRLFact

    logger = structlog.get_logger(__name__)


    class ScoringOrchestrator:
        """Bridges pure scoring functions to the database.

        Reads Filing + XBRLFact rows, converts to typed inputs,
        calls pure scorers, writes SignalDetail rows.
        """

        def __init__(
            self,
            session: Session,
            config: ScoringConfig | None = None,
            scoring_date: date | None = None,
            run_id: uuid.UUID | None = None,
        ):
            self._session = session
            self._config = config or ScoringConfig()
            self._scoring_date = scoring_date or date.today()
            self._run_id = run_id or uuid.uuid4()
    ```

    **Key methods:**

    `_load_filings(self, company_id: uuid.UUID) -> list[FilingForScoring]`:
    - Query Filing where company_id matches and form_type in ("10-K", "10-Q").
    - Convert each to FilingForScoring: `year = f.period_of_report.year if f.period_of_report else f.filing_date.year`, `sections = f.sections` (already a dict from JSONB).
    - Sort by year ascending for determinism.

    `_load_xbrl_facts(self, company_id: uuid.UUID, concept: str) -> list[tuple[int, str, int]]`:
    - Query XBRLFact where company_id matches and concept matches.
    - Return list of `(fact.fiscal_year, fact.fiscal_period, fact.value_cents)` tuples.
    - Sort by fiscal_year ascending for determinism.

    `score_company(self, company_id: uuid.UUID, ticker: str) -> list[SignalResult]`:
    - Load filings, rd_facts (concept="rd_expense"), capex_facts (concept="capex").
    - Compute SEC filing score using `compute_sec_filing_score(filings, rd_facts, scoring_year=self._scoring_date.year, window_years=self._config.sec_filing.window_years, section_weights=self._config.sec_filing.section_weights, sigmoid_midpoint=self._config.sec_filing.sigmoid_midpoint, sigmoid_steepness=self._config.sec_filing.sigmoid_steepness)`.
    - Compute keyword counts by year (intermediate result from SEC scoring pipeline) using `compute_keyword_counts_by_year(filings)`. Extract `{year: result.total_weighted_count}` dict.
    - Compute compute spending score using `compute_compute_spending_score(filings, capex_facts, ai_keyword_counts_by_year, scoring_year=self._scoring_date.year, window_years=self._config.compute_spending.window_years, capex_weight=self._config.compute_spending.capex_weight, cloud_mention_weight=self._config.compute_spending.cloud_mention_weight, sigmoid_midpoint=self._config.compute_spending.sigmoid_midpoint, sigmoid_steepness=self._config.compute_spending.sigmoid_steepness)`.
    - Collect non-None results. Log per signal: `logger.info("signal_scored", company_id=str(company_id), ticker=ticker, signal_type=result.signal_type, score=result.score)`.
    - Log if a signal returned None: `logger.info("signal_skipped", company_id=str(company_id), ticker=ticker, signal_type="sec_filing", reason="insufficient_data")`.
    - Return list of SignalResult.

    `persist_signals(self, company_id: uuid.UUID, results: list[SignalResult]) -> int`:
    - For each SignalResult, check if SignalDetail already exists for `(company_id, signal_type, as_of_date=self._scoring_date)`. If exists, skip (idempotent).
    - If not, create SignalDetail: `company_id=company_id, signal_type=result.signal_type, score=result.score, evidence=result.evidence, run_id=self._run_id, as_of_date=self._scoring_date`.
    - `self._session.add(detail)`, `self._session.flush()`.
    - Return count of new rows inserted.

    `score_all(self) -> list[tuple[str, list[SignalResult]]]`:
    - Query all active Company where `is_active=True` and `cik IS NOT NULL`.
    - Sort by ticker for determinism.
    - For each company: `results = self.score_company(company.id, company.ticker)`, `self.persist_signals(company.id, results)`.
    - Log summary: `logger.info("scoring_complete", companies_scored=N, signals_persisted=M, run_id=str(self._run_id))`.
    - Return list of `(ticker, results)` tuples.
