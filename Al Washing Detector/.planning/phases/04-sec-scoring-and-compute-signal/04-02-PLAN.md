    **Function 2: compute_filing_mismatch_ratio**

    ```python
    def compute_filing_mismatch_ratio(
        keyword_counts_by_year: dict[int, float],
        rd_spend_by_year: dict[int, int],
        window_years: int = 3,
        scoring_year: int | None = None,
    ) -> tuple[float | None, dict]:
    ```

    - Per D-03: 3-year rolling window. Per D-04: ratio = `(1 + keyword_growth_cagr) / (1 + rd_growth_cagr)`.
    - `scoring_year` defaults to max year in keyword_counts_by_year.
    - `start_year` = `scoring_year - window_years`.
    - Compute keyword CAGR using `compute_cagr(max(start_kw, 0.1), end_kw, window_years)`. The 0.1 floor prevents zero-start issues while preserving the growth direction.
    - Compute R&D CAGR using `compute_cagr(max(start_rd, 1), end_rd, window_years)`. The 1 floor (1 cent) prevents zero-division.
    - If either start or end data is missing for the window, return `(None, {"error": "insufficient_[keyword|rd]_data"})`.
    - Compute ratio: `kw_factor = 1.0 + (kw_growth or 0.0)`, `rd_factor = 1.0 + (rd_growth or 0.0)`. If `rd_factor <= 0`, clamp to `0.01`.
    - Return `(ratio, evidence_dict)` where evidence_dict contains `keyword_growth_cagr`, `rd_growth_cagr`, `mismatch_ratio`, `window_start_year`, `window_end_year`.
