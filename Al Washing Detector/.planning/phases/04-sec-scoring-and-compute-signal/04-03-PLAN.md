    **Function 2: compute_capex_keyword_gap**

    ```python
    def compute_capex_keyword_gap(
        ai_keyword_counts_by_year: dict[int, float],
        capex_by_year: dict[int, int],
        cloud_mentions_by_year: dict[int, int],
        window_years: int = 3,

        capex_weight: float = 0.70,
        cloud_mention_weight: float = 0.30,
    ) -> tuple[float | None, dict]:
    ```

    - Per D-05: Compute `capex_growth` CAGR over the window.
    - Compute `ai_keyword_growth` CAGR over the window (reusing the same keyword counts from the SEC scoring pipeline -- passed in, not recomputed).
    - Compute `cloud_mention_growth`: if cloud mentions exist for start and end years, compute CAGR. If not, treat cloud_mention_factor as 0 (no boost or penalty).
    - Combined gap metric: The spending gap is the divergence of AI narrative growth from investment growth. Compute `investment_growth = capex_weight * capex_growth_factor + cloud_mention_weight * cloud_growth_factor` where each factor is `(1 + cagr)`. Then `gap_ratio = (1 + ai_keyword_growth) / investment_growth`.
    - If investment_growth <= 0, clamp to 0.01.
    - If CapEx data is missing for the window, return `(None, {"error": "insufficient_capex_data"})`.
    - Return `(gap_ratio, evidence_dict)` with capex_growth_cagr, cloud_mention_growth, keyword_growth_cagr, combined_gap_ratio, weights used.
