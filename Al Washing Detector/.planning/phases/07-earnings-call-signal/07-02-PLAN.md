  <action>
    1. Create src/ai_washer/ingestion/earnings_collector.py following GitHubCollector/PatentCollector pattern:
       - class EarningsCollector:
         - __init__(self, app_settings: AppSettings | None = None) -> None:
           - Lazy load app_settings if None
           - Create EarningsClient(api_key=app_settings.earningscall_api_key)
           - Create engine + session_factory from app_settings
           - _default_quarters: int = 8 (last 8 quarters = 2 years)
           - structlog logger bound with collector="earnings_collector"
         - collect_for_company(self, company_id: uuid.UUID, ticker: str, num_quarters: int | None = None, collection_date: date | None = None) -> EarningsCollectionResult:
           - Determine which (year, quarter) pairs to fetch: last num_quarters quarters from today
           - For each (year, quarter): check DB for existing transcript (idempotent skip), call client.get_transcript, persist EarningsTranscript row
           - CRITICAL DATA CONTRACT: transcript_text JSONB stores ONLY string sections:
             {"full_text": text, "prepared_remarks": prepared_text_or_None, "qa": qa_text_or_None}
             All values MUST be str | None -- no dicts, no nested objects.
             The downstream scorer (07-04) concatenates all non-None values expecting strings.
           - speakers dict (from TranscriptRecord.speakers) goes into collection_metadata:
             {"signal_version": EARNINGS_SIGNAL_VERSION, "collected_at": iso_timestamp, "speakers": speakers_dict}
           - as_of_date = transcript_date or date(year, quarter*3, 1) approximation
           - observed_date = collection_date
           - Return EarningsCollectionResult with counts
         - collect_all(self, collection_date: date | None = None) -> list[EarningsCollectionResult]:
           - Query active companies with CIK
           - Call collect_for_company for each
           - Sleep _INTER_COMPANY_DELAY (1.0s) between companies
           - Log progress every 10 companies
         - _transcript_exists(self, session, company_id, year, quarter) -> bool: check unique constraint columns
       - _INTER_COMPANY_DELAY = 1.0
       - _PROGRESS_LOG_INTERVAL = 10
