       - Pre-compile earnings lexicon at module level:
         _EARNINGS_PATTERNS = compile_lexicon(EARNINGS_VAGUE_TERMS, EARNINGS_SUBSTANTIVE_TERMS)
       - def compute_earnings_vagueness_score(
             transcript_text: dict[str, str | None],
             sentiment_result: SentimentResult,
             ai_claim_intensity: float | None,
             buzzword_weight: float = 0.70,
             sentiment_weight: float = 0.30,
             sigmoid_midpoint: float = 1.0,
             sigmoid_steepness: float = 2.0,
         ) -> SignalResult | None:
         - Handle ai_claim_intensity None case:
           - If None: default to _DEFAULT_AI_CLAIM_INTENSITY (0.5), set ai_claim_intensity_defaulted=True
           - If 0.0: return None (company makes no AI claims, earnings vagueness is irrelevant)
           - If > 0.0: use as-is, set ai_claim_intensity_defaulted=False
         - Concatenate all non-None string values from transcript_text dict
           NOTE: transcript_text values are guaranteed to be str | None (per 07-02 data contract).
           No type coercion needed -- if a value is not a string, that is a bug upstream.
         - Return None if concatenated text is empty
         - Count vague and substantive keywords using count_keywords_in_text with _EARNINGS_PATTERNS
         - buzzword_density_ratio = vague_count / max(vague_count + substantive_count, 1)
         - sentiment_mismatch = sentiment_result.positive * (1.0 - substantive_ratio)
           where substantive_ratio = substantive_count / max(vague_count + substantive_count, 1)
         - raw_score = buzzword_weight * buzzword_density_ratio + sentiment_weight * sentiment_mismatch
         - score = sigmoid_normalize(raw_score, midpoint=sigmoid_midpoint, steepness=sigmoid_steepness)
         - Build evidence dict with: signal_version, buzzword_density_ratio, vague_count, substantive_count, sentiment (positive/negative/neutral from SentimentResult), scoring_params (buzzword_weight, sentiment_weight, sigmoid_midpoint, sigmoid_steepness), ai_claim_intensity, ai_claim_intensity_defaulted
         - Return SignalResult(signal_type="earnings_vagueness", score=score, evidence=evidence)
