    1. Create src/ai_washer/analysis/finbert_analyzer.py:
       - class SentimentResult(BaseModel): positive (float), negative (float), neutral (float). Add model_validator to ensure sum ~= 1.0 (tolerance 0.05).
       - def chunk_text_for_bert(text: str, tokenizer, max_tokens: int = 510) -> list[str]:
         - Encode text without special tokens
         - Split into chunks of max_tokens
         - Decode each chunk back to text
         - Pure function, no side effects
       - class FinBERTAnalyzer:
         - __init__(self, model_name: str = "ProsusAI/finbert") -> None:
           - Lazy-load: store model_name, set _pipe and _tokenizer to None
           - Actual loading happens on first analyze_text call
         - _ensure_loaded(self) -> None:
           - If _pipe is None: load transformers.pipeline("sentiment-analysis", model=model_name, tokenizer=model_name, batch_size=8, truncation=True, max_length=512) and AutoTokenizer.from_pretrained(model_name)
           - Log model loading event via structlog
         - analyze_text(self, text: str) -> SentimentResult:
           - If empty text: return SentimentResult(positive=0.0, negative=0.0, neutral=1.0)
           - Call _ensure_loaded()
           - Chunk text via chunk_text_for_bert(text, self._tokenizer, max_tokens=510)
           - Run self._pipe(chunks) -- returns list of {"label": "positive"|"negative"|"neutral", "score": float}
           - Aggregate: for each label, compute mean probability across all chunks
           - Return SentimentResult with aggregated probabilities
         - analyze_segments(self, segments: dict[str, str | None]) -> dict[str, SentimentResult]:
           - Runs analyze_text on each non-None segment
           - Returns {segment_name: SentimentResult}
       - structlog logger
    2. Create tests/unit/test_finbert_analyzer.py:
       - CRITICAL: Mock transformers.pipeline and AutoTokenizer -- do NOT download actual FinBERT model in tests
       - Mock pipeline to return [{"label": "positive", "score": 0.7}, ...] style responses
       - Mock tokenizer.encode to return fake token IDs of controlled length
       - Mock tokenizer.decode to return text chunks
       - Test all 6 behaviors
    3. Run ruff format and check.
