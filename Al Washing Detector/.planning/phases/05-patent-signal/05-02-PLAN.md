    3. _build_query(self, assignee_name: str, cpc_prefixes: tuple[str, ...], after_date: date | None) -> dict:
       Build the PatentSearch API query dict per research Code Example:
       ```
       {"_and": [
           {"_contains": {"assignees.assignee_organization": assignee_name}},
           {"_or": [
               {"_begins": {"cpc_current.cpc_group_id": prefix}} for prefix in cpc_prefixes
           ]},
           # Optionally: {"_gte": {"patent_date": after_date.isoformat()}} if after_date
       ]}
       ```

    4. _fetch_page(self, query: dict, size: int = 100, after: str | None = None) -> dict:
       Execute single API call to GET {base_url}/patent/ with params:
       - q: json.dumps(query)
       - f: json.dumps(["patent_id", "patent_title", "patent_date", "assignees.assignee_organization", "cpc_current.cpc_group_id"])
       - o: json.dumps({"size": size} | ({"after": after} if after else {}))
       Decorate with @retry(wait=wait_exponential(min=0.1, max=60), stop=stop_after_attempt(5), retry=retry_if_exception(...)) for 429/5xx.
       Handle 401/403 -> PatentClientError("Authentication failed...request API key at...")
       Handle 400 -> PatentClientError("Invalid query...")
       Return response.json()

    5. search_by_assignee(self, assignee_name: str, cpc_prefixes: tuple[str, ...] = CPC_AI_PREFIXES, after_date: date | None = None) -> list[PatentRecord]:
       - If api_key is empty, raise PatentClientError with message about requesting key at https://patentsview-support.atlassian.net/servicedesk/customer/portal/1/group/1/create/18
       - Paginate: call _fetch_page in a loop. Extract patents from response. If count == page_size and response has cursor/after token, fetch next page. Cap at 10 pages max (safety).
       - Parse each patent dict into PatentRecord: extract patent_id, patent_title, patent_date, first assignees.assignee_organization, collect all cpc_current.cpc_group_id values.
       - Return deduplicated list (by patent_id).

    1. PatentCollector class following FilingCollector pattern:
       - __init__(self, app_settings: AppSettings | None = None):
         Load AppSettings, create PatentSearchClient with api_key and base_url from settings.
         Create engine and session factory from app_settings.

    2. _get_last_patent_date(self, session: Session, company_id: uuid.UUID) -> date | None:
       Query MAX(patent_date) from patents table WHERE company_id matches.
       Returns None if no patents exist for this company (first collection).

    3. _get_assignee_names(self, company: Company) -> list[str]:
       Extract patent_assignee list from company.aliases dict (parse through AliasesSchema if needed).
       If empty, fall back to [company.name].
       Return deduplicated list.

    4. collect_for_company(self, company_id: uuid.UUID, company_name: str, aliases: dict) -> PatentCollectionResult:
       - Get assignee names from aliases (or fall back to company_name)
       - Open session, get last_patent_date for incremental collection
       - For each assignee name, call patent_client.search_by_assignee(name, after_date=last_patent_date)
       - Deduplicate all PatentRecords by patent_id across all assignee searches
       - For each unique patent: check if already in DB (SELECT by company_id + patent_id), skip if exists
       - Insert new Patent rows: company_id, patent_id, patent_title, patent_date, assignee_organization, cpc_codes (as list in JSONB), as_of_date=patent_date, collection_metadata={signal_version, assignee_names_searched, api_query_count}
       - Commit and return PatentCollectionResult
       - Wrap PatentClientError in try/except: log warning, add to result.errors, return partial result

    5. collect_all(self) -> list[PatentCollectionResult]:
       - Query active companies with CIK
       - For each company, call collect_for_company
       - Inter-company delay of 1.0 second (time.sleep) per Phase 3 pattern
       - Log progress with structlog
