**Pure functions (module-level, no class needed):**

1. `deduplicate_by_period(entries: list[dict]) -> list[dict]`:
   - For each unique (end, fp) pair, keep entry with latest `filed` date
   - Per Pitfall 3: handles amended filings (10-K/A) superseding originals

2. `extract_facts_for_concept(concept: str, facts_json: dict, form_filter: str | None = "10-K") -> list[XBRLFactRecord]`:
   - Look up tag list from `XBRL_TAG_GROUPS[concept]`
   - Navigate `facts_json["facts"]["us-gaap"]`
   - Try each tag in order -- use first one with USD entries
   - Filter by form_filter if specified (exact match, not prefix -- "10-K" excludes "10-K/A")
   - Call `deduplicate_by_period` on matching entries
   - Convert each entry to XBRLFactRecord:
     - `tag`: the actual matched XBRL tag name
     - `concept`: the normalized concept name (e.g. "rd_expense")
     - `end_date`: parse `entry["end"]` as `date`
     - `value_cents`: `int(entry["val"] * 100)` -- dollar to cents conversion (same as EdgarFactsClient pattern)
     - `fiscal_year`: `entry["fy"]`
     - `fiscal_period`: `entry["fp"]`
     - `form_type`: `entry["form"]`
     - `filed_date`: parse `entry["filed"]` as `date`
     - `accession_no`: `entry["accn"]`
   - Return list of XBRLFactRecord

3. `extract_all_facts(facts_json: dict, form_filter: str | None = "10-K") -> dict[str, list[XBRLFactRecord]]`:
   - Call `extract_facts_for_concept` for each concept in XBRL_TAG_GROUPS
   - Return dict mapping concept name -> list of records

**Class (for API access with rate limiting):**

4. `class XBRLExtractor`:
   - `__init__(self, edgar_identity: str)`: create httpx.Client with User-Agent header (same as EdgarFactsClient pattern)
   - `__enter__` / `__exit__` context manager
   - `get_company_facts(self, cik: str) -> dict | None`: fetch `XBRL_FACTS_URL.format(cik=pad_cik(cik))`, return JSON dict, return None on 404, retry on 429/5xx via tenacity
   - `extract_company_xbrl(self, cik: str) -> list[XBRLFactRecord]`: call get_company_facts, then extract_all_facts, flatten into single list sorted by end_date desc

Reuse from edgar_client.py:

- Same tenacity retry decorator pattern
