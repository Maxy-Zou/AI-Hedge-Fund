```python
class FilingClient:
    """Wrapper around edgartools for SEC filing retrieval and section extraction.

    Parameters
    ----------
    edgar_identity:
        SEC-compliant User-Agent string, e.g. "CompanyName email@example.com".
    settings:
        FilingCollectionSettings for section limits and filing counts.
    """
```

Key methods:

1. `__init__(self, edgar_identity: str, settings: FilingCollectionSettings | None = None)`:
   - Store edgar_identity and settings (default FilingCollectionSettings())
   - Call `edgar.set_identity(edgar_identity)` (Pitfall 5 mitigation)
   - Initialize structlog logger

2. `__enter__` / `__exit__` for context manager (no HTTP client to close since edgartools manages its own connections, but keep pattern for consistency)

3. `get_latest_filings(self, form_type: str, cik: str, count: int | None = None) -> list[FilingData]`:
   - Default count: settings.max_annual_filings for 10-K, settings.max_quarterly_filings for 10-Q, settings.max_8k_filings for 8-K
   - Use `edgar.Company(cik)` to look up company (try CIK first)
   - Call `company.get_filings(form=form_type)` to get filings collection
   - Take `filings.latest(count)` for most recent N
   - For each filing, call `_extract_filing_data(filing, form_type)` to parse
   - Catch exceptions at per-filing level -- log and skip failed filings
   - Return list[FilingData]

4. `_extract_filing_data(self, filing, form_type: str) -> FilingData`:
   - Extract metadata: `filing.accession_number`, `filing.filing_date`, `filing.period_of_report`
   - For 10-K: call `filing.obj()` to get TenK, extract sections via bracket notation:
     - `tenk["Item 1"]` -> business
     - `tenk["Item 1A"]` -> risk_factors
     - `tenk["Item 7"]` -> mda
   - For 10-Q: call `filing.obj()` to get TenQ, extract:
     - `tenq["part1item2"]` or similar -> mda (10-Q has abbreviated sections)
   - For 8-K: use `filing.text()` for full_text_excerpt (8-Ks lack standard section structure)
   - Apply `_truncate_section(text, max_chars)` to each section
   - Apply `_validate_section_length(text, section_name)` -- if < 500 chars, log warning and populate full_text_excerpt as fallback (Pitfall 1 mitigation)
   - Compute `content_hash` as `hashlib.sha256(concatenated_sections.encode()).hexdigest()`
   - Return FilingData

5. `_truncate_section(self, text: str | None, max_chars: int) -> str | None`:
   - Return None if text is None
   - Return text[:max_chars] if len(text) > max_chars

6. `_validate_section_length(self, text: str | None, section_name: str, filing_accession: str) -> bool`:
   - If text is not None and len(text) < 500, log warning with section_name and accession
   - Return True if valid (>= 500 chars or None), False if suspiciously short
