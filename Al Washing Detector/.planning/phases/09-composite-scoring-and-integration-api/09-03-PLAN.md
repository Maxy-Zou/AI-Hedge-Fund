    1. Create src/ai_washer/api.py:
       - Module docstring: "Public Python API for the AI Washing Detector. Returns frozen dataclasses -- no ORM models leak to consumers."
       - from __future__ import annotations
       - Imports: uuid, date, datetime from datetime; Session from sqlalchemy.orm; select, func from sqlalchemy; CompanyScore from api_types; DailyScore, Company, SignalDetail from db.models; classify_risk_band, ALL_SIGNAL_TYPES from analysis.composite_scorer; get_session_factory from db.session
       - logger = structlog.get_logger(__name__)

    2. Helper function _build_signal_freshness(company_id: uuid.UUID, session: Session) -> dict[str, date]:
       - Query SignalDetail WHERE company_id = company_id, GROUP BY signal_type, SELECT signal_type, MAX(as_of_date)
       - Returns dict mapping signal_type -> latest as_of_date
       - Used to populate CompanyScore.signal_freshness (per INT-03)

    3. Helper function _row_to_company_score(row: DailyScore, company: Company, session: Session) -> CompanyScore:
       - Extract signals_available from signal_breakdown keys (sorted)
       - Compute signals_missing = sorted(set(ALL_SIGNAL_TYPES) - set(signal_breakdown keys))
       - NOTE: signal_breakdown keys are signal_type names (e.g., "sec_filing", "earnings_vagueness"), so match directly against ALL_SIGNAL_TYPES
       - Call _build_signal_freshness(row.company_id, session) to populate signal_freshness
       - Return CompanyScore with all fields mapped from DailyScore + Company

    4. get_score(ticker: str, score_date: date | None = None, *, session: Session | None = None) -> CompanyScore | None:
       - If session is None, create one via get_session_factory()
       - Look up Company by ticker (case-insensitive: func.upper(Company.ticker) == ticker.upper())
       - If not found, return None
       - If score_date is None: query DailyScore for company_id ORDER BY scored_at DESC LIMIT 1
       - If score_date provided: query DailyScore WHERE func.date(scored_at) == score_date AND company_id, LIMIT 1
       - If no row, return None
       - Return _row_to_company_score(row, company, session)

    5. get_latest_scores(*, session: Session | None = None) -> list[CompanyScore]:
       - If session is None, create one
       - Subquery: for each company_id, find max(scored_at)
       - Join DailyScore with Company on company_id
       - Filter: scored_at == max per company (use window function or subquery)
       - Order by composite_score DESC
       - Return list of CompanyScore via _row_to_company_score

    6. get_score_history(ticker: str, start_date: date, end_date: date, *, session: Session | None = None) -> list[CompanyScore]:
       - If session is None, create one
       - Look up Company by ticker (case-insensitive), return [] if not found
       - Query DailyScore WHERE company_id AND func.date(scored_at) >= start_date AND func.date(scored_at) <= end_date
       - Order by scored_at ASC
       - Return list of CompanyScore

    7. Update src/ai_washer/__init__.py to re-export the public API functions:
       - Read the existing file first to preserve any current exports
       - Add: `from ai_washer.api import get_score, get_latest_scores, get_score_history`
       - Add `__all__` entry (or extend existing) to include the three function names
       - This allows downstream consumers to do `from ai_washer import get_score` directly
