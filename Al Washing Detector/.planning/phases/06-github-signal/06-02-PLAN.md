    1. Define GitHubClientError(Exception) at module level.

    2. Define _is_retryable(exc) function: retry on 429 and 5xx HTTPStatusError, same as patent_client.py.

    3. Define _DEPENDENCY_FILES = ("requirements.txt", "pyproject.toml", "setup.py", "setup.cfg") as module constant.

    4. Create class GitHubClient with:
       - __init__(self, token: str, base_url: str = "https://api.github.com", client: httpx.Client | None = None):
         - Lazy token validation (accept empty at construction, raise GitHubClientError on use)
         - If client is None, create httpx.Client with timeout=30.0 and headers: Authorization: Bearer {token}, Accept: application/vnd.github+json, X-GitHub-Api-Version: 2022-11-28
         - Track self._rate_limit_remaining: int | None = None
         - Track self._owns_client for cleanup

       - _update_rate_limit(self, response: httpx.Response) -> None:
         Read x-ratelimit-remaining header, update self._rate_limit_remaining.

       - @retry(wait=wait_exponential(min=0.1, max=60), stop=stop_after_attempt(5), retry=retry_if_exception(_is_retryable), reraise=True)
         _get(self, path: str, params: dict | None = None, headers: dict | None = None) -> httpx.Response:
         - Validate token is not empty, raise GitHubClientError if it is
         - Make GET request, call _update_rate_limit, raise for 401/403 as GitHubClientError, raise_for_status for others
         - Return response

       - list_org_repos(self, org: str, max_repos: int = 100) -> list[GitHubRepoRecord]:
         - GET /orgs/{org}/repos with params: type=public, sort=pushed, direction=desc, per_page=100
         - Paginate until max_repos or empty page
         - Skip repos where fork=True
         - Parse each repo dict into GitHubRepoRecord (repo_full_name from full_name, repo_name from name, primary_language from language, pushed_at parsed from ISO string, is_fork, is_archived, stargazers_count, language_bytes={} initially, ml_frameworks=[] initially)
         - Return all_repos[:max_repos]

       - get_repo_languages(self, owner: str, repo: str) -> dict[str, int]:
         - GET /repos/{owner}/{repo}/languages
         - Return response.json() (already a dict[str, int])

       - get_file_content(self, owner: str, repo: str, path: str) -> str | None:
         - GET /repos/{owner}/{repo}/contents/{path} with extra header Accept: application/vnd.github.raw+json
         - Return response.text on 200
         - Return None on 404 (catch httpx.HTTPStatusError where status_code == 404)
         - Re-raise other errors

       - scan_ml_frameworks(self, owner: str, repo: str) -> list[str]:
         - For each file in _DEPENDENCY_FILES, call get_file_content
         - Check content_lower against ML_FRAMEWORK_PATTERNS from github_types
         - Return sorted list of detected framework keys (deduplicated)

       - build_org_snapshot(self, org: str, max_repos: int = 100, reference_date: date | None = None) -> GitHubOrgSnapshot:
         - Call list_org_repos to get repos
         - For each non-archived repo: call get_repo_languages (update repo.language_bytes), call scan_ml_frameworks (update repo.ml_frameworks)
         - Aggregate: total_language_bytes, total_ml_language_bytes (sum bytes for languages in ML_LANGUAGES), ml_language_ratio = ml_bytes/total_bytes (0.0 if no bytes)
         - Compute days_since_last_push from most recent pushed_at vs reference_date (default date.today())
         - Merge all ml_frameworks_found across repos (deduplicated, sorted)
         - Return GitHubOrgSnapshot

       - @property rate_limit_remaining(self) -> int | None: expose tracked value

       - close(self) -> None: close client if self._owns_client

    5. Write comprehensive tests in tests/unit/test_github_client.py using pytest-httpx for HTTP mocking. Follow the test_patent_client.py structure. Use freezegun for date-dependent tests (days_since_last_push).
