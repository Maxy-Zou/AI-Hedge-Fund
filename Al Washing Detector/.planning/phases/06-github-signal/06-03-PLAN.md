    3. Pure function compute_github_activity_score with signature:
       ```python
       def compute_github_activity_score(
           repo_count: int,
           ml_language_ratio: float,        # 0.0-1.0
           days_since_last_push: int | None, # None = no repos
           ml_frameworks_found: list[str],
           ai_claim_intensity: float,        # weighted keyword count from SEC filings
           scoring_year: int,
           recency_decay_days: int = 365,
           sigmoid_midpoint: float = 1.0,
           sigmoid_steepness: float = 2.0,
       ) -> SignalResult | None:
       ```

    4. Logic:
       - If ai_claim_intensity <= 0 and repo_count == 0: return None (nothing to compare)
       - If ai_claim_intensity <= 0: return None (no claims to measure gap against)
       - If repo_count == 0 and ai_claim_intensity > 0: return SignalResult(signal_type="github_activity", score=95, evidence={...}) -- max washing with zero GitHub
       - Otherwise compute four sub-factors, each 0.0-1.0:
         a) repo_factor = min(repo_count / 20.0, 1.0) -- 20+ repos = full credit
         b) language_factor = ml_language_ratio (already 0-1)
         c) recency_factor = max(0.0, 1.0 - (days_since_last_push / recency_decay_days)) if days_since_last_push is not None else 0.0
         d) framework_factor = min(len(ml_frameworks_found) / 3.0, 1.0) -- 3+ frameworks = full credit
       - github_factor = (repo_factor * 0.2 + language_factor * 0.3 + recency_factor * 0.3 + framework_factor * 0.2) -- weighted average of sub-factors
       - Clamp github_factor minimum to 0.01 (prevent division by zero)
       - claim_factor = min(ai_claim_intensity / 50.0, 2.0) -- normalize claims to ~1.0 range, cap at 2.0
       - gap_ratio = claim_factor / github_factor
       - score = sigmoid_normalize(gap_ratio, midpoint=sigmoid_midpoint, steepness=sigmoid_steepness)
       - Build evidence dict with: signal_version, repo_count, ml_language_ratio, days_since_last_push, ml_frameworks_found (list), ai_claim_intensity (rounded), sub_factors (dict of all four factors), github_factor, claim_factor, gap_ratio, scoring_year
       - Return SignalResult(signal_type="github_activity", score=score, evidence=evidence)

    5. Write comprehensive tests in tests/unit/test_github_activity_scorer.py covering all behaviors. Follow the test_patent_gap_scorer.py parametrize style for edge cases.
