    - Test 3: check_staleness flags source with last_success_at=None as "never_succeeded"
    - Test 4: StalenessReport is frozen dataclass with source_name, reason, hours_since (float|None), expected_hours (int)
    - Test 5: update_source_status sets last_success_at and is_stale=False on success

    - Test 7: get_all_source_status returns list of all DataSourceStatus records
  </behavior>
  <action>
    Create src/ai_washer/pipeline/monitoring.py with `from __future__ import annotations`:

    1. `@dataclass(frozen=True)` StalenessReport: source_name (str), reason (str), hours_since (float | None), expected_hours (int)
    2. `def check_staleness(session: Session) -> list[StalenessReport]`:
       - Queries all DataSourceStatus rows
       - For each: if last_success_at is None -> StalenessReport(reason="never_succeeded", hours_since=None)
       - If (now_utc - last_success_at).total_seconds()/3600 > expected_cadence_hours -> StalenessReport(reason="exceeded_cadence", hours_since=computed, expected_hours=...)
       - Also updates is_stale column on the DataSourceStatus row as side effect
       - Returns list of stale StalenessReports
    3. `def update_source_status(session: Session, source_name: str, *, success: bool, error_message: str | None = None) -> None`:
       - Finds DataSourceStatus by source_name (or creates if missing)
       - On success=True: set last_success_at=now, is_stale=False
       - On success=False: set last_error_at=now, last_error_message=error_message, is_stale=True
       - Flush the session (do not commit -- caller manages transaction)
    4. `def get_all_source_status(session: Session) -> list[DataSourceStatus]`:
       - Returns all DataSourceStatus rows ordered by source_name

    Tests use SQLite in-memory DB with DataSourceStatus table created via Base.metadata.create_all (following existing test pattern). Use freezegun to mock datetime for staleness calculations.
