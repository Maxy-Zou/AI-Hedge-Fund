    Each function follows the pattern:
    ```python
    def collect_X_stage(session, settings):
        try:
            collector = XCollector(...)
            results = collector.collect_all()
            total = sum(r.collected for r in results)
            errors = [e for r in results for e in r.errors]
            return StageResult(stage="X", status="succeeded" if not errors else "partially_failed", companies_processed=total, errors=errors)
        except Exception as exc:
            logger.warning("stage_failed", stage="X", error=str(exc), exc_info=True)
            return StageResult(stage="X", status="failed", errors=[str(exc)])
    ```

    NOTE: the status logic above is intentional — `"succeeded"` when no errors, `"partially_failed"` when some records had errors, `"failed"` only when the entire stage throws an unhandled exception. This matches the `StageResult.status` contract in types.py.

    **IMPORTANT on Prefect:** Use Prefect @flow decorator ONLY on daily_pipeline_flow. Do NOT use @task on individual stages. The existing collectors have their own retry logic via tenacity. Prefect @task adds unnecessary complexity for sync code that already handles retries. Instead, call stage functions directly from the flow.

    Flow logic:
    1. Load settings via load_app_settings()
    2. Create engine + session
    3. Call mark_stale_runs(session) to clean up crashed runs
    4. Call start_pipeline_run(session) to get run_id + bind correlation ID
    5. Run ingestion stages sequentially (SEC compliance rate limits):
       - sec_result = collect_sec_filings_stage(session, settings)
       - update_source_status(session, "sec_filings", success=sec_result.status=="succeeded", ...)
       - patent_result = collect_patents_stage(session, settings)
       - update_source_status(session, "patents", ...)
       - github_result, earnings_result, jobs_result similarly
    6. Commit session after ingestion
    7. Run scoring stage: score_result = score_all_stage(session, settings, run_id)
    8. Commit session after scoring
    9. Call end_pipeline_run(session, run_id, all_stages)
    10. Commit and return PipelineRunResult

    All in a try/finally that ensures end_pipeline_run and session.close() are called.
