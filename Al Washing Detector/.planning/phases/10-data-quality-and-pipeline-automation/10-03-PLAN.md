    - Test 4: end_pipeline_run clears structlog contextvars
    - Test 5: end_pipeline_run sets status="succeeded" when all stages succeeded
    - Test 6: end_pipeline_run sets status="partially_failed" when some stages failed but others succeeded
    - Test 7: end_pipeline_run sets status="failed" when all stages failed
    - Test 8: end_pipeline_run stores per-source errors in JSONB format: [{"stage": "patents", "errors": ["timeout"]}]
    - Test 9: Stale run detection: mark_stale_runs sets status="crashed" on PipelineRun rows with status="running" older than threshold_hours
  </behavior>
  <action>
    Create src/ai_washer/pipeline/correlation.py with `from __future__ import annotations`:

    1. `def start_pipeline_run(session: Session) -> uuid.UUID`:
       - Generate run_id = uuid.uuid4()
       - Clear any existing contextvars: clear_contextvars()
       - Bind: bind_contextvars(run_id=str(run_id), pipeline="daily_batch")
       - Create PipelineRun(id=run_id, status="running") and add to session, flush
       - Log: logger.info("pipeline_run_started", run_id=str(run_id))
       - Return run_id

    2. `def end_pipeline_run(session: Session, run_id: uuid.UUID, stages: list[StageResult]) -> PipelineRunResult`:
       - Query PipelineRun by run_id
       - Compute status: "succeeded" if all stages status=="succeeded", "failed" if all stages status=="failed", else "partially_failed"
       - Compute companies_processed: max(s.companies_processed for s in stages) or 0
       - Build errors JSONB: [{"stage": s.stage, "errors": s.errors} for s in stages if s.errors]
       - Update PipelineRun: ended_at=now_utc, status=computed, companies_processed=computed, errors=computed
       - Flush session
       - Log: logger.info("pipeline_run_ended", run_id=str(run_id), status=computed, total_errors=sum of error counts)
       - Clear contextvars: clear_contextvars()
       - Return PipelineRunResult with all fields

    3. `def mark_stale_runs(session: Session, threshold_hours: int = 4) -> int`:
       - Query PipelineRun where status="running" and started_at < now - threshold_hours
       - Set status="crashed", ended_at=now for each
       - Return count of marked runs

    Tests use SQLite in-memory DB with PipelineRun table. Verify contextvars binding via structlog.contextvars.get_contextvars().
