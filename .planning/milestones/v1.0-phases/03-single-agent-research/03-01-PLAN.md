1. Create src/ai_hedge_fund/agents/research.py:

```python
"""Research agent with tool-augmented investment thesis generation.

Uses PydanticAI dependency injection (RunContext[ResearchDeps]) to pass
pipeline context (ticker, as_of_date) to thin tool wrappers that call
Phase 2 data tools. The LLM controls tool selection and optional parameters
(e.g., lookback_days), but NEVER controls ticker or as_of_date.

Produces ThesisOutput with evidence-cited bull/bear cases.
"""
from __future__ import annotations

from dataclasses import dataclass
from datetime import date
from typing import Any

from pydantic_ai import Agent, RunContext
from sqlalchemy.orm import Session

from ai_hedge_fund.config import AppSettings
from ai_hedge_fund.data.tools import (
    get_filing_sections,
    get_financial_summary,
    get_insider_clusters,
    get_macro_context,
    get_news_sentiment,
    get_price_history,
)
from ai_hedge_fund.models import ModelTier
from ai_hedge_fund.schemas.agents import ThesisOutput


@dataclass(frozen=True)
class ResearchDeps:
    """Immutable dependency container for the research agent.
    
    Carries pipeline context through to tool calls via RunContext.
    LLM never controls these values -- they come from pipeline state.
    """
    ticker: str
    as_of_date: date
    db_session: Session | None = None
    settings: AppSettings | None = None


research_agent: Agent[ResearchDeps, ThesisOutput] = Agent(
    ModelTier.ANALYSIS.value,
    output_type=ThesisOutput,
    deps_type=ResearchDeps,
    retries=2,
)
```

2. Add dynamic system prompt via decorator:
```python
@research_agent.system_prompt
def research_system_prompt(ctx: RunContext[ResearchDeps]) -> str:
    return f"""\
You are a senior equity research analyst producing an investment thesis for {ctx.deps.ticker}.

CRITICAL RULES:
1. NEVER state a financial figure (revenue, earnings, price, ratio, growth rate) unless it came from a tool call. If you have not called a tool for a metric, do not mention it.
2. You are analyzing as of {ctx.deps.as_of_date.isoformat()}. You have NO knowledge of events after this date. Do not reference any events, earnings, or data that occurred after {ctx.deps.as_of_date.isoformat()}.
3. You MUST call get_financials and get_price_data at minimum before forming your thesis.
4. You MUST call at least one of: get_insider_activity, get_sentiment, get_macro_environment.
5. Every bull and bear case point MUST cite the specific tool and data that supports it in the source_tool and evidence fields.
6. Your bull case needs at least 3 points, bear case at least 3 points, risk factors at least 2.
7. Confidence score (0-100) should reflect evidence strength, not your prior beliefs about the company.
"""
```

3. Add 6 tool wrappers using @research_agent.tool:

- `fetch_filings(ctx, form_type="10-K", max_filings=3) -> str`: Calls get_filing_sections, returns formatted sections text. LLM controls form_type and max_filings. Returns a text summary of the filing sections (join the section contents).

- `get_financials(ctx) -> str`: Calls get_financial_summary, returns result["summary_text"]. No LLM-controlled params beyond tool selection.

- `get_price_data(ctx, lookback_days=252) -> str`: Calls get_price_history, returns summary_text + formatted stats dict (NOT the raw prices list -- token budget protection).

- `get_insider_activity(ctx, lookback_days=90) -> str`: Calls get_insider_clusters, returns result["summary_text"].

- `get_sentiment(ctx, lookback_days=7) -> str`: Calls get_news_sentiment, returns result["summary_text"].

- `get_macro_environment(ctx) -> str`: Calls get_macro_context (no ticker -- macro is market-wide), returns result["summary_text"].

Each wrapper: extracts ticker from ctx.deps.ticker, as_of_date from ctx.deps.as_of_date, db_session from ctx.deps.db_session, settings from ctx.deps.settings. All function docstrings describe what the tool returns (PydanticAI extracts docstrings for the LLM tool descriptions).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM -> Tool Params | LLM chooses which tools to call and optional params (lookback_days), but ticker/as_of_date/session come from deps |
| Filing Text -> LLM | SEC filing text is untrusted external input -- could contain adversarial content |
| LLM -> ThesisOutput | LLM generates thesis content validated by Pydantic schema |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | LLM generates financial numbers without tool | mitigate | System prompt forbids it + Langfuse trace verification in Plan 03 |
| T-03-02 | Information Disclosure | Temporal data leakage via LLM training data | mitigate | System prompt restricts to as_of_date + all tools enforce @enforce_as_of_date |
| T-03-03 | Tampering | LLM controls ticker/as_of_date via tool params | mitigate | ResearchDeps DI -- ticker and as_of_date injected from pipeline state, not LLM args |
| T-03-04 | DoS | Token budget exhaustion from large tool responses | mitigate | Tool wrappers return summary_text only (not raw prices/articles); UsageLimits on every run() |
| T-03-05 | Tampering | Filing text contains prompt injection | accept | Low risk: PydanticAI treats tool returns as data; schema validation catches malformed output |
</threat_model>
