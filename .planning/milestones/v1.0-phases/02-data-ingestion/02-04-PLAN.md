       - `class FinnhubClient`:

           Returns empty list on API errors (graceful degradation).

           Calls `self._client.news_sentiment(ticker)`.
           Returns {buzz_score, weekly_average, company_score, sector_average} or None.
           Used to supplement per-article sentiment with aggregate scores.

       - `class FredClient`:
         - `__init__(self, api_key: str)`: Creates `Fred(api_key=api_key)`.

         - `get_series(self, series_id: str, observation_start: date | None = None, observation_end: date | None = None) -> pd.Series`:
           Calls `self._fred.get_series(series_id, observation_start=..., observation_end=...)`.
           Returns pandas Series with DatetimeIndex.
           Uses tenacity @retry(stop=stop_after_attempt(3), wait=wait_exponential(min=1, max=10)).
         - `get_latest_values(self, as_of_date: date) -> dict[str, float | None]`:
           For each series in FRED_SERIES:
             Calls get_series(series_id, observation_end=as_of_date).
             Takes the last non-NaN value.
           Returns dict mapping series name -> latest value (or None if unavailable).
         - `compute_cpi_yoy(self, as_of_date: date) -> float | None`:
           Gets CPI for as_of_date and 12 months prior. Returns YoY percentage change.
         - `compute_gdp_growth(self, as_of_date: date) -> float | None`:
           Gets real GDP for as_of_date quarter and prior quarter. Returns QoQ annualized growth.
