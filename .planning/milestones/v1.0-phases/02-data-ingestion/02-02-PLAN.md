<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| edgartools -> app | SEC EDGAR data via edgartools library; public data but responses must be validated |
| tool caller -> tool | as_of_date crosses from agent to tool; must be validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-02-04 | Tampering | edgar_client.py | mitigate | Filter filings by filing_date (not period_of_report) to prevent look-ahead bias |
| T-02-05 | Tampering | xbrl_client.py | mitigate | Convert monetary values to cents at ingestion; use filed_date filtering |
| T-02-06 | Denial of Service | edgar_client.py | mitigate | tenacity retry with exponential backoff; SEC 10 req/sec rate limit respected via sleep |
| T-02-07 | Information Disclosure | edgar_client.py | accept | EDGAR data is public; no confidential data in this boundary |
| T-02-08 | Spoofing | xbrl_client.py | mitigate | XBRL tag fallback validates concept exists in taxonomy before using |
</threat_model>
