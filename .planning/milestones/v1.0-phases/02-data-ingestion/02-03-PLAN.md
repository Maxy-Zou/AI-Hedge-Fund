<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| yfinance -> app | Unofficial API, may return incorrect data or fail silently |
| tiingo -> app | Paid API, requires API key in request header |
| edgartools (Form 4) -> app | SEC public data, but Form 4 parsing may have edge cases |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-02-09 | Tampering | price_client.py | mitigate | Cross-validate yfinance vs Tiingo when both available; log discrepancies |
| T-02-10 | Denial of Service | price_client.py | mitigate | Cache-first pattern avoids repeated external calls; tenacity retry with backoff |
| T-02-11 | Information Disclosure | price_client.py | mitigate | Tiingo API key not logged; passed only in authenticated requests |
| T-02-12 | Tampering | form4_client.py | mitigate | Filter on filing_date not trade_date for temporal correctness |
| T-02-13 | Elevation of Privilege | price_tools.py | accept | Tool functions run in same process as agents; no privilege boundary to cross |
</threat_model>
