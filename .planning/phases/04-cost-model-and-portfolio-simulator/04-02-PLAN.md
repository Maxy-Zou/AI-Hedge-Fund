Vectorized math formulas (from RESEARCH.md):
```python
# Gross returns (NO additional shift — WeightFrame already shifted)
daily_returns = prices.pct_change()        # NaN for row 0
tickers = weights.columns.intersection(daily_returns.columns)
gross_per_ticker = weights[tickers] * daily_returns[tickers]
gross_returns = gross_per_ticker.sum(axis=1)  # skipna=True by default

# Transaction costs
bps_per_trade = (slippage_bps + commission_bps) / 10_000
weight_change = weights.diff().abs()
transaction_costs = (weight_change * bps_per_trade).sum(axis=1)

# Borrow costs
daily_borrow_rate = borrow_cost_bps_annual / 10_000 / 252
short_weights = weights.clip(upper=0.0).abs()
borrow_costs = (short_weights * daily_borrow_rate).sum(axis=1)

# Net returns
net_returns = gross_returns - transaction_costs - borrow_costs
```
