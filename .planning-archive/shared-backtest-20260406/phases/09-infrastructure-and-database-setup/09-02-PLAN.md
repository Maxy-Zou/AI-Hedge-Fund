Expected output should show two rows: `ai_washer_alembic_version` and `fund_backtest_alembic_version`.

```bash
docker compose restart

  -c "SELECT * FROM fund_backtest_alembic_version;"
docker exec ai_hedge_fund_postgres psql -U hedge -d ai_hedge_fund \

```
