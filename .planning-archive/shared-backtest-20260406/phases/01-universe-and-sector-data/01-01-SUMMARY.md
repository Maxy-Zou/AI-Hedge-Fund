## Decisions Made

- `fund-backtest` is independent from `ai_washer` — no shared Python imports (mirrors Project constraint)
- Used `TimestampMixin` (not `AppendOnlyMixin`) for `UniverseTicker` because it is a mutable entity that gets updated in-place, not an append-only audit record
- `UniverseSnapshot` has no `updated_at` — it is an immutable audit log per immutability convention
- `market_cap_cents` stored as `BigInteger` to handle values up to 9.2 quadrillion cents without floating-point precision loss
- `sector_breakdown` stored as JSONB to allow arbitrary sector aggregates without schema changes as the universe evolves
- `cli.py` stub added as deviation (Rule 2) since `__main__.py` imports it — extended in Plan 02
