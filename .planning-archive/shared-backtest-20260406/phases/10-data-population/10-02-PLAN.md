    STEP 2 — Run universe refresh:
    ```bash
    cd "/Users/maxzou/Documents/projects/AI Hedgefund/backtest"
    FUND_BACKTEST_DATABASE_URL="postgresql+psycopg://hedge:hedge@localhost:5432/ai_hedge_fund" \
      PYTHONPATH="$(pwd)/src" \
      .venv/bin/fund-backtest universe refresh 2>&1
    ```

    CRITICAL: Do NOT use `uv run fund-backtest` — Python 3.12 skips .pth files in venvs when the path contains spaces ("AI Hedgefund"). Use `.venv/bin/fund-backtest` with explicit `PYTHONPATH` only.
    Do NOT use `export $(grep -v '^#' .env | xargs)` — .env contains spaces in EDGAR_IDENTITY value.

    The command will:
    1. Fetch the Wikipedia S&P 400 table (~400 companies)
    2. Query yfinance for each ticker's current market cap (with 1s delay between requests)
    3. Filter to the $2B–$10B range (market_cap_min=200_000_000_000 cents, max=1_000_000_000_000 cents)
    4. Upsert results into universe_tickers, write a snapshot row

    Expected runtime: 5-15 minutes (yfinance queries for ~400 tickers with 1s delay each).

    Expected output:
    ```
              Universe Refresh Complete
    ┌─────────────────┬────────────────────────┐
    │ Metric          │ Value                  │
    ├─────────────────┼────────────────────────┤
    │ Snapshot date   │ 2026-03-30 (today)     │
    │ Active tickers  │ 150-350                │
    │ New tickers     │ 150-350                │
    │ Removed tickers │ 0                      │
    └─────────────────┴────────────────────────┘
    ```

    If the command exits 1 (error): Read the error output. Common causes:
    - Container not running → `docker compose up -d`
    - Wrong DATABASE_URL → check .env at repo root for FUND_BACKTEST_DATABASE_URL
    - Wikipedia table scraping failed → yfinance/Wikipedia network issue, retry

    STEP 3 — Verify result with universe status:
    ```bash
    cd "/Users/maxzou/Documents/projects/AI Hedgefund/backtest"
    FUND_BACKTEST_DATABASE_URL="postgresql+psycopg://hedge:hedge@localhost:5432/ai_hedge_fund" \
      PYTHONPATH="$(pwd)/src" \
      .venv/bin/fund-backtest universe status 2>&1
    ```
    Expected: Shows "Active tickers: N" where N is between 150 and 350, plus a sector breakdown table.

    STEP 4 — Direct SQL verification:
    ```bash
    docker exec ai_hedge_fund_postgres psql -U hedge -d ai_hedge_fund \
      -c "SELECT COUNT(*) AS active, (SELECT COUNT(*) FROM universe_snapshots) AS snapshots FROM universe_tickers WHERE is_active = TRUE;"
    ```
    Expected: active >= 150, snapshots >= 1.

    STEP 5 — Verify GICS sectors are populated (not all NULL):
    ```bash
    docker exec ai_hedge_fund_postgres psql -U hedge -d ai_hedge_fund \
      -c "SELECT gics_sector, COUNT(*) FROM universe_tickers WHERE is_active = TRUE GROUP BY gics_sector ORDER BY COUNT(*) DESC LIMIT 5;"
    ```

    Expected: Multiple sector rows with real sector names (Industrials, Technology, Health Care, etc.), NOT all NULL.
