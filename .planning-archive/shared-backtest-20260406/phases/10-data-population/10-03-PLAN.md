    2. Split tickers into batches of 80

    5. Print a Download Complete table

    ```
    │ Tickers successful   │ 195-340        │
    │ Tickers failed       │ 0-10 (normal)  │
    │ Bars inserted        │ 200,000-500,000│
    └──────────────────────┴────────────────┘
    ```

    WATCH FOR warnings in structlog output:
    - `tickers_failed_in_batch` or `Tickers failed > 0` means some batches hit yfinance rate limits
    - If `Tickers failed` is > 10% of requested, the batch_sleep_secs may need to be increased further
    - If rate limiting occurs, `data download` is idempotent — re-run will skip already-inserted bars

    If the download errors mid-way:
    - Check structlog output for the specific error
    - Re-run the same command — ON CONFLICT DO NOTHING means re-running is safe
    - The second run will only download bars missing from price_bars
