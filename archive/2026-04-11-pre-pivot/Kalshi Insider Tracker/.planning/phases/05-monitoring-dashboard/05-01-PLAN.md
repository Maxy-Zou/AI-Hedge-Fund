    series_ticker: Mapped[str]

    no_ask: Mapped[int]

    volume: Mapped[int]           # Integer
    volume_24h: Mapped[int]
    status: Mapped[str]
    captured_at: Mapped[datetime]
    raw_snapshot: Mapped[dict]    # JSONB

class Signal(AppendOnlyMixin, Base):
    __tablename__ = "signals"
    # AppendOnlyMixin adds: id (UUID pk), created_at
    ticker: Mapped[str]
    signal_type: Mapped[str]      # 'volume_spike' | 'price_move'
    confidence: Mapped[float]     # 0.0 – 1.0
    details: Mapped[dict]         # JSONB
    detected_at: Mapped[datetime]

class Trade(AppendOnlyMixin, Base):

**get_markets(session)** implementation:
- Use a subquery to find max(captured_at) per ticker from market_snapshots
- Join MarketSnapshot on (ticker, captured_at) = subquery result
- Join Market on ticker = market.ticker WHERE market.status = 'active'
- Return list of dicts: {ticker, title, status, last_price, volume, captured_at}
- Use `session.query(...)` style (not select() — consistent with existing codebase patterns)
- Wrap in try/except Exception, return [] on error, log warning with structlog

**get_recent_signals(session, limit=50)** implementation:
- `session.query(Signal).order_by(Signal.detected_at.desc()).limit(limit).all()`
- Return list of dicts: {ticker, signal_type, confidence, detected_at, details}
- Wrap in try/except, return [] on error

**get_open_positions(session)** implementation:
- `session.query(Trade).filter(Trade.status.in_(["pending", "filled"])).order_by(Trade.placed_at.desc()).all()`
- Return list of dicts: {ticker, side, contracts, price_cents, mode, status, placed_at}
- Wrap in try/except, return [] on error

**get_pnl_summary(session)** implementation:
- Query all trades: `session.query(Trade).all()`
- trade_count = len(trades)
- total_contracts = sum(t.contracts for t in trades)
- total_cost_cents = sum(t.contracts * t.price_cents for t in trades)
- realized_pnl_cents = 0  # TODO: compute from settled trades when Kalshi settled price is stored
- Return dict: {trade_count, total_contracts, total_cost_cents, realized_pnl_cents}
- Wrap in try/except, return {trade_count: 0, total_contracts: 0, total_cost_cents: 0, realized_pnl_cents: 0} on error
