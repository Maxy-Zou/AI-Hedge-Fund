    Algorithm (exactly as designed in RESEARCH.md):
    ```
    now = snapshots[-1].captured_at
    lookback_cutoff = now - timedelta(minutes=lookback_minutes)
    cluster_cutoff = now - timedelta(minutes=cluster_minutes)

    # Filter to lookback window
    window_snaps = [s for s in snapshots if s.captured_at >= lookback_cutoff]
    if len(window_snaps) < 12:  # min_snapshots guard
        return None

    # Compute volume deltas (consecutive differences, clamp negatives to 0)
    # Pair each snapshot with its previous: delta[i] = max(window_snaps[i].volume_24h - window_snaps[i-1].volume_24h, 0)
    # delta[0] = 0 (no previous to diff against)
    deltas = [0] + [max(window_snaps[i].volume_24h - window_snaps[i-1].volume_24h, 0)
                    for i in range(1, len(window_snaps))]

    total_volume = sum(deltas)
    if total_volume < min_total_volume:
        return None

    # Identify "recent" snapshots (within cluster_minutes of now)
    recent_deltas = [deltas[i] for i, s in enumerate(window_snaps)
                     if s.captured_at >= cluster_cutoff]
    recent_volume = sum(recent_deltas)

    concentration = recent_volume / total_volume
    if concentration <= cluster_threshold:
        return None

    confidence = min(max((concentration - cluster_threshold) / (1.0 - cluster_threshold), 0.0), 1.0)
    ```
