    BacktestRunner:
    - `__init__(self, repo: MarketRepository, fill_engine: FillEngine | None = None)`
    - `def run(self, strategy: Strategy, start_date: datetime, end_date: datetime, series_tickers: list[str] | None = None) -> BacktestResult:`
      1. Load markets via repo.get_markets(min_close_time=start_date, max_close_time=end_date, ...series filter)
      2. Bulk-load candles: for each market ticker, repo.get_candles(ticker, start_ts=start_date) — collect into dict[str, list[dict]]
      3. Construct BarIterator(markets, candles_by_ticker)
      4. Main loop: for snapshot in bar_iterator:
         - Call strategy.generate_signals(snapshot, tracker.open_positions)
         - For each signal: try_fill → if Fill, tracker.open(fill)
         - If snapshot.result is not None and ticker not yet settled: tracker.settle(ticker, result, snapshot.ts)
      5. Build BacktestResult from tracker state
    - structlog run-level logging: run_id, bar_count, market_count, fill_count
