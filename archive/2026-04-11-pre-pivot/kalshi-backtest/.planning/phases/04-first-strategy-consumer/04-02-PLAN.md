Strategy Protocol (structural — no inheritance):
```python
def generate_signals(
    self,
    snapshot: MarketSnapshot,   # .ticker: str, .ts: datetime (naive UTC), .close_price: int (cents)
    open_positions: list[Position],  # .ticker: str per position
) -> list[Signal]: ...
```

Signal constructor:
```python
Signal(
    ticker="KXBTC-24DEC-T50000",
    direction="yes",    # Literal["yes", "no"]
    contracts=1,        # int >= 1
    limit_price=45,     # int [0, 100] in cents
    reason="strategy:reason",
)
```

Insider Tracker `signals` table (raw SQL only — no ORM import from kalshi_tracker):
```sql
SELECT signal_type, confidence, details
FROM signals
WHERE ticker = :ticker
  AND detected_at >= :start
  AND detected_at < :end       -- strictly less-than for look-ahead safety
  AND confidence >= :min_conf
ORDER BY detected_at DESC
LIMIT 1
```
Column types: signal_type TEXT, confidence FLOAT, details JSON/JSONB.

SQLAlchemy text() pattern:
```python
from sqlalchemy import create_engine, text
from sqlalchemy.orm import sessionmaker
engine = create_engine(database_url, pool_pre_ping=True)
session_factory = sessionmaker(engine)
with session_factory() as session:
    rows = session.execute(text("SELECT ..."), {...}).fetchall()
```
