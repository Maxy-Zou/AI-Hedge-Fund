      4. Compute Sharpe for each result: daily_pnl.mean() / daily_pnl.std() if std > 0 else 0.0
      5. Sort by Sharpe descending, return list[SweepResult]
    - structlog logging: log each sweep run with params and sharpe

    GREEN implementation:
    Split logic:
    - total_days = (end_date - start_date).days
    - fold_days = total_days // n_splits
    - If fold_days < 14 (minimum meaningful window): raise ValueError
    - Train window = fold [0..k-1], test window = fold [k] for k in 1..n_splits
    - Simplification: expanding window (train grows with each fold, test is always the next fold)
    - train_start always = start_date
    - For fold k (0-indexed): test_start = start_date + k * fold_days, test_end = start_date + (k+1) * fold_days
    - train_end = test_start (day before test window starts)
    - runner.run() called twice per fold: once for train window (for parameter optimization), once for test window

    WalkForwardResult: frozen dataclass with train_start, train_end, test_start, test_end, train_result (BacktestResult), test_result (BacktestResult)
